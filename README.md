# Belot Friends — мультиплеерный браузерный белот

Тёмный адаптивный интерфейс, комнаты по коду, 4 игрока, две команды, Socket.IO-события в реальном времени.

## Бесплатный запуск на компьютере

1. Установите Node.js 18 или новее: https://nodejs.org/
2. Распакуйте архив.
3. Откройте терминал в папке проекта.
4. Выполните:
   ```bash
   npm install
   npm start
   ```
5. Откройте http://localhost:3000.

Чтобы играть по одной Wi-Fi сети, остальные игроки могут открыть `http://IP-ВАШЕГО-ПК:3000` (разрешите Node.js в брандмауэре). `localhost` на их устройствах не подойдёт.

## Бесплатный запуск через интернет

Подойдёт бесплатный Node.js-хостинг, поддерживающий постоянный процесс и WebSockets (например, Render free web service, если бесплатный тариф доступен вашему аккаунту и региону).

1. Создайте приватный или публичный Git-репозиторий и загрузите содержимое архива.
2. Создайте Web Service из репозитория.
3. Build command: `npm install`
4. Start command: `npm start`
5. Не задавайте фиксированный порт — приложение использует `process.env.PORT`.
6. Дождитесь публикации HTTPS-адреса и отправьте его друзьям. Один создаёт комнату и передаёт код.

Бесплатные тарифы хостингов могут засыпать при простое, иметь лимиты и меняться. Если хостинг не поддерживает WebSockets или длительно работающие Node-процессы, эта сборка там не заработает.

## Важно о правилах

Это игровой MVP, а не сертифицированная реализация всех региональных правил болгарского белота. Сейчас есть 32 карты, торговля, козырные режимы, ходы по масти, взятки и матч до 1000 очков. Перед серьёзной игрой следует согласовать детали начисления очков/контрактов: в разных компаниях и регионах правила различаются. В частности, проверка обязательного перебивания/надбивания и объявлений (терцы, кварты, квинты, белот-ребелот) пока не реализована.

## Безопасность и ограничения MVP

- Комнаты хранятся в памяти сервера; перезапуск хостинга удалит текущие игры.
- Переподключение после потери соединения пока не восстанавливает место автоматически.
- Используйте приватную ссылку/код только с друзьями.
- Нет аккаунтов, чата, ботов или сохранения статистики.
