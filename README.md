# Belot Friends — белот для четырёх игроков

Браузерная мультиплеерная игра на Node.js, Express и Socket.IO. Создайте комнату, передайте код трём друзьям и играйте в командах Север–Юг и Восток–Запад.

## Правила этой версии

- 4 игрока, две команды: места 0/2 и 1/3.
- Колода из 24 карт: 9, 10, валет, дама, король, туз каждой масти.
- Перед каждой раздачей случайно выбирается одна козырная масть. Торговли нет.
- По 6 карт на игрока, всего 6 взяток.
- Нужно ходить в масть, если она есть. Если масти нет — играть козырь, если он есть; если возможно, перебивать козырь старше, когда старший козырь принадлежит сопернику.
- Очки карт: обычная масть — туз 11, 10 = 10, король 4, дама 3, валет 2, девятка 0; козырь — валет 20, девятка 14, туз 11, 10 = 10, король 4, дама 3. Последняя взятка даёт 10 очков.
- Терц (3 подряд одной масти) — 20, полтина (4 подряд) — 50, сотка (5 или 6 подряд) — 100.
- Каре: четыре валета — 200, четыре девятки — 150, четыре десятки/дам/королей/тузов — 100.
- Белот: дама и король козырной масти — 20 очков.
- Очки каждой команды за раздачу округляются к ближайшему числу, оканчивающемуся на 0 или 5. Матч до 1000 очков.

## Важно про комбинации

Реализация автоматически находит комбинации в исходной руке. Для комбинаций выбирается старшая по силе; если старшие комбинации равны у обеих команд, очки за комбинации не начисляются. Белот начисляется отдельно. Региональные варианты правил белота отличаются, поэтому перед игрой стоит согласовать спорные детали. Это дружеский игровой прототип, а не официальный судья турнира.

## Запуск на компьютере

1. Установите Node.js 18 или новее: https://nodejs.org/
2. Распакуйте архив.
3. В папке проекта выполните:
   ```bash
   npm install
   npm start
   ```
4. Откройте http://localhost:3000.

## Игра с друзьями

Для локальной сети остальные игроки могут открыть `http://IP-ВАШЕГО-ПК:3000` (разрешите Node.js в брандмауэре). Для игры через интернет загрузите проект на хостинг, который поддерживает постоянный Node.js-процесс и WebSockets.

## Ограничения

- Комнаты хранятся в памяти сервера и исчезают при его перезапуске.
- После потери соединения игроку пока нужно подключаться заново.
- Автоматическая проверка комбинаций и правила перебивания — упрощённая реализация выбранного набора правил; желательно протестировать за реальным столом и уточнить региональные варианты.
